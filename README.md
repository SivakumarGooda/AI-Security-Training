# AI Security Research

Research material on AI/LLM security architecture, controls, and testing tools.

## Contents

| File | Description |
|---|---|
| `AI.pptx` | Training deck: AI system architecture and security components — orchestration layer, RAG pipeline, prompt builder, LLM, and the guardrails applied around each stage (input, RAG, tool/API pre- and post-calls, output). |
| `LLM Tools.xlsx` | Comparison of AI security tooling — Garak, PyRIT, PyRIT-Ship, Burp AI Agent, LLM Guard, Promptfoo, Prompt Fuzzer, ART, Privacy Meter, DeepTeam, and agentic/MCP testing tools — with evaluation notes and references. |

## Usage

Open the files with PowerPoint and Excel (or LibreOffice). No macros or
embedded active content are used.

## Scope

These are research and training notes, not runnable tools. The tools mentioned
in the spreadsheet are third-party projects; follow their licenses and use them
only against systems you are authorized to test.
